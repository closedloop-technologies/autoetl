# Data Model Validation

We have two scenarios when working with modeling data from examples.

We typically have a mix of a data model (or schema) and a set of example data.

We often have two goals when working with data models and example data:

1. Validate the example data against the data model
2. Generate or modify a data model to fit the example data

We have a few tools that can help us with this.

## JSON Schema

We can use a JSON schema to validate example data.

We can also use example data to generate a JSON schema.

We can use the `jsonschema` library to validate example data against a JSON schema.

We can use the `jsonschema` library to generate a JSON schema from example data.

## OpenAPI

We can use OpenAPI to validate example data.

We can also use example data to generate an OpenAPI schema.

We can use the `openapi-spec-validator` library to validate example data against an OpenAPI schema.

We can use the `openapi-spec-validator` library to generate an OpenAPI schema from example data.

## Example Data

We can use example data to generate a data model.

We can use example data to modify a data model.

We can use the `pandas` library to generate a data model from example data.

We can use the `pandas` library to modify a data model from example data.

## Example Data and Data Model

We can use example data to validate a data model.

We can use a data model to validate example data.

We can use example data to generate a data model.

We can use a data model to generate example data.

We can use example data to modify a data model.
